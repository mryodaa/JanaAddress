# Справочник адресов

Справочник собирается нашими скриптами из открытых источников в один файл `reference/reference.sqlite`, который кладётся в образ. Сеть нужна только при сборке: рантайм сервиса в интернет не ходит. Строки из `train.json` никуда не отправляются и в справочник не попадают: там только топонимы.

## Источники и лицензии

|----------|-----------|----------------------|

## Как собрать заново

```bash
pip install -e ".[build]"                                  # osmium, shapely, openpyxl
python scripts/build_reference/download.py osm             # ~220 МБ, с докачкой
python scripts/build_reference/osm_extract.py              # -> cache/osm_raw.jsonl
python scripts/build_reference/assign_districts.py         # -> cache/osm_assigned.json
# КАТО: скачать файл классификатора с stat.gov.kz в cache/, затем
python scripts/build_reference/kato.py cache/kato.xlsx     # -> cache/kato.json
python scripts/build_reference/build_sqlite.py --osm scripts/build_reference/cache/osm_assigned.json \
       --kato scripts/build_reference/cache/kato.json      # -> reference/reference.sqlite + coverage.json
```

Без OSM и КАТО `build_sqlite.py` собирает справочник из одного ядра: сервис работает, но без улиц и домов.

## Как считается принадлежность к району

1. Полигоны районов (admin_level 6 внутри города республиканского значения; admin_level 7–9 «... район» внутри городской администрации) индексируются в `shapely.STRtree`.
2. Дом относится к району по точке (центроид здания). Улица получает веса по трём точкам (начало, середина, конец) и по всем своим домам.
3. В рантайме (`pipeline/reference_step.py`):
   * дом найден в справочнике → район дома;
   * иначе улица в одном районе или доминирующий район ≥ 80% весов → этот район;
   * иначе `district = null`, флаг `district_ambiguous` понижает confidence.
4. Город улицы или дома: полигон города республиканского значения → полигон `place=city/town/village` → ближайший населённый пункт в радиусе (город 12 км, посёлок 5 км, село 2.5 км).

## Схема `reference.sqlite`

`provinces`, `districts` (kind: oblast | city), `cities` (kind: republican | city | town | village), `living_areas`, `streets`, `street_districts` (веса), `houses` (номер + ключ сравнения), `aliases` (etype, eid, alias, fold-ключ, язык, источник), `meta`. Схема: `scripts/build_reference/schema.sql`.

Районы внутри города есть в OSM только у Алматы (8), Астаны (6), Шымкента (5) и Тараза (2). Поэтому районом размечены почти все дома этих городов. У остальных областных центров районов в OSM нет: для Караганды и Актобе районы есть только в ядре, без полигонов, и район по дому там не восстанавливается.
